Introduction
----------

 Dans ce tuto, on va voir comment installer Proxmox sur Raspberry Pi.  
 En effet depuis début aout 2026, Proxmox Virtual Environment est dispo depuis aout 2026 sur l'architecture ARM64.  
[https://forum.proxmox.com/threads/proxmox-virtual-environment-now-available-for-64-bit-arm-arm64.185526/](https://forum.proxmox.com/threads/proxmox-virtual-environment-now-available-for-64-bit-arm-arm64.185526/)  

 Bien que proxmox ne supporte pas les Raspberry Pi (image ISO ARM64) on va pouvoir avoir quelque chose de fonctionnel en partant d'une install de Raspberry Pi OS (qui est une Debian, base de proxmox Virtual Environment)  

 Les limites seront la configuration du Raspberry Pi utilisé, sa mémoire RAM et la qualité du stockage.  

Prérequis
----------

 Préparer un disque externe avec Raspberry Pi OS lite (64-bit) dessus (sans interface graphique), au moins basée sur Trixie.  
 On n'utilisera pas le wi-fi (qui ne sera pas top avec un pont réseau nécessaire pour Proxmox Virtual Environment.  

Préparation du Raspberry Pi
----------

 Une fois le Pi démarré sur Raspberry Pi OS, on se connecte en root :  

Code BASH :

```
sudo -i
```

 On définit un mot de passe à root :  

Code BASH :

```
passwd root
```

 On met à jour complet le Raspberry Pi :  

Code BASH :

```
apt update && apt full-upgrade -y
```

 On désactive cloud-init qui est utilisé pour ne pas regénérer de la config qui parasite le futur proxmox :  

Code BASH :

```
touch /etc/cloud/cloud-init.disabled
```

 Si on veut on peut virer cloud-init mais c'est un peu radical (et on ne pourra plus non plus utiliser la fonction cloud-init de proxmox) :  

Code BASH :

```
apt purge cloud-init
```

 Repérer les infos IP via :  

Code BASH :

```
ip a
```

 Chez moi :  

Code TEXT :

```
2: eth0:  mtu 1500 qdisc mq state UP group default qlen 1000
    link/ether dc:a6:32:3c:9e:fc brd ff:ff:ff:ff:ff:ff
    inet 192.168.21.136/24 brd 192.168.21.255 scope global dynamic noprefixroute eth0
       valid_lft 85246sec preferred_lft 85246sec
    inet6 fe80::dea6:32ff:fe3c:9efc/64 scope link noprefixroute
       valid_lft forever preferred_lft forever
```

 On va fixer le nom de la machine dans le fichier hosts, car Proxmox l'utilise (adapter avec l'IP et le nom que vous avez) :  

Code BASH :

```
echo "192.168.21.136 pimox" >> /etc/hosts
```

 On ajoute le dépôt de Proxmox pour la bonne édition :  

Code BASH :

```
cat > /etc/apt/sources.list.d/pve-install-repo.sources << EOL
Types: deb
URIs: http://download.proxmox.com/debian/pve
Suites: $(lsb_release -sc)
Components: pve-no-subscription
Signed-By: /usr/share/keyrings/proxmox-archive-keyring.gpg
EOL
```

 On récupère la clé GPG de proxmox qu'on intègre :  

Code BASH :

```
wget https://enterprise.proxmox.com/debian/proxmox-archive-keyring-$(lsb_release -sc).gpg -O /usr/share/keyrings/proxmox-archive-keyring.gpg
```

 On rafraichit la liste des logiciels :  

Code BASH :

```
apt update
```

 On va désactiver NetworkManager car proxmox utilise le bon vieux fichier interfaces :  

Code BASH :

```
systemctl disable --now NetworkManager
```

 On installe le gestionnaire réseau de base requis par Proxmox et les outils bridge-utils :  

Code BASH :

```
apt install ifupdown2 bridge-utils
```

 On renseigne la config réseau souhaitée en IP Fixe dans le fichier interfaces :  

Code BASH :

```
nano /etc/network/interfaces
```

 Voici ce que j'ajoute pour la config ethernet (je fais le bridge dès à présent) :  

Code TEXT :

```
iface eth0 inet manual
        hwaddress ether dc:a6:32:3c:9e:fc
iface wlan0 inet manual
auto vmbr0
iface vmbr0 inet static
        address 192.168.21.136/24
        gateway 192.168.21.254
        hwaddress ether dc:a6:32:3c:9e:fc
        bridge-ports eth0
        bridge-stp off
        bridge-fd 0
```

On fixe l'adresse MAC avec celle retournée précédemment via **ip a** car parfois elle change sur mon Raspberry Pi  

 Normalement le fichier /etc/resolv.conf n'est pas à modifier car il a déjà les infos DNS correctes (le commentaire indiquant NetworkManager n'a pas d'importance) :  

Code TEXT :

```
# Generated by NetworkManager
search linuxtricks.lan
nameserver 192.168.21.251
```

 On peut si besoin désinstaller NetworkManager en plus de l'avoir désactivé :  

Code BASH :

```
apt purge network-manager
```

 Avant d'installer Proxmox, on reboot un coup pour valider que tout est OK notamment le réseau :  

Code BASH :

```
reboot
```

Installation de Proxmox
----------

 Une fois notre Raspberry Pi redémarré, on passe à l'installation de Proxmox !  

 On rebascule en root :  

Code BASH :

```
sudo -i
```

 On rafraichit les sources :  

Code BASH :

```
apt update
```

 On installe les paquets qui vont bien :  

Code BASH :

```
apt install proxmox-ve pve-manager qemu-server pve-cluster chrony
```

 Pas de panique, on voit des paquets suivants se supprimer : firmware-atheros firmware-brcm80211 firmware-libertas firmware-realtek  

 On n'a pas besoin du noyau de Proxmox, puisque celui de Raspberry Pi est optimisé pour le matériel et a toutes les options pour supporter les conteneurs et VMs.

----------

[https://192.168.21.136:8006/](https://192.168.21.136:8006/)
